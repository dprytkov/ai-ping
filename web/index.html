Добавить из Windows

          
%USERPROFILE%\.claude\.credentials.json
Setup-token выполняет пинги без статистики лимитов.
Для обновления авторизации войдите в нужный аккаунт в Windows и загрузите свежий файл. Импорт не делает запросов к модели.

          
Импортировать текущие аккаунты одним скриптом
Скрипт прочитает файлы Claude и Codex в вашем текущем профиле Windows и добавит оба аккаунта. Для подключения понадобится логин и пароль этой панели.
Скачать скрипт для Windows
Сохраните файл, откройте PowerShell в его папке и выполните:
powershell -NoProfile -ExecutionPolicy Bypass -File .\Import-WindowsAccounts.ps1
API-ключи и refresh-токены не переносятся. Подписка на сервере обновляется повторным импортом.
